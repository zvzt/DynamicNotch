# DynamicNotch 3.5.0

DynamicNotch 3.5.0 updates the public release to the current macOS notch-style Now Playing build.

### Downloads

- `DynamicNotch.dmg` — packaged macOS application
- `DynamicNotch.command` — Terminal/Finder installer using zxt.lol

### Highlights

- Apple Music direct metadata, playback, seek, volume, and artwork handling
- Spotify support
- Browser Now Playing integration
- Optional enhanced Firefox bridge
- Launch at Login
- Updated notch UI, progress controls, and settings
